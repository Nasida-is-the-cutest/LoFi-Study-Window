# Lo-Fi 学习小窗 · 首次公开发布

**本 MOD 基于并借鉴参考开源项目 [iGPU Savior](https://github.com/Small-tailqwq/iGPUSaviorMod)，原作者为 Small-tailqwq，原项目采用 MIT 许可证。本项目保留原版权声明与许可证，并在此基础上改进。**

本次发行标识为 `learning-window-2026-10-21`，插件兼容基线及内部版本保持 `1.9.4`。这是本衍生项目的首次公开安装包，与上游 iGPU Savior 的 v1.9.4 发行不同。

## 下载与安装

普通用户下载 **LoFi-Study-Window-learning-window-2026-10-21.zip**，解压后阅读 `README.md`，双击 `安装.cmd`，或将包内 `BepInEx/plugins/iGPU Savior.dll` 复制到游戏目录对应位置。首次使用 MOD 需先安装 Windows x64 版 BepInEx 5；本包不捆绑加载器。

安装前退出游戏。脚本会先备份旧 DLL 和配置，安装后通过 Steam 正常启动即可。运行 `卸载.cmd` 可恢复先前 DLL，配置和存档不会被覆盖。下载页同时提供 `SHA256SUMS.txt`。

## 功能

- 原游戏番茄钟的置顶小窗、大号剩余时间与暂停／继续。
- 默认静态背景，支持低帧率动画切换；音乐保留。
- 无顶部说明文字，三个同色半透明圆角按钮，普通状态透明度 58%。
- 顶部拖动、边缘缩放、窗口位置记忆，F3 返回原窗口。
- 修复主线程调度、窗口归属检查、资源释放、设置注册和低帧率计时等问题。

## 验证边界

已在游戏 1.17.3、Unity 2022.3.62f2、Windows x64 与 BepInEx 5.4.23.5 上验证；其他游戏版本尚未逐一验证。主项目构建通过，165 项逻辑回归通过，四种窗口尺寸的隔离界面布局和按钮命中检查通过。安装脚本另外在模拟游戏目录中验证备份、升级和卸载。

既有完整功能、窗口与 25+5 分钟计时记录见 `docs/VALIDATION.md`。此次公开发行构建去除了调试路径；不会把游戏程序集、存档、测试探针或本地日志打包。电池功耗尚未完成实测，不承诺固定百分比的续航提升。
